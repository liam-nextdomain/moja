# Moja 앱 아이콘 제작 지시서

작성일: 2026-09-09 · 대상 버전: v1.0.0

> **현재 상태**: 이 지시서에 맞춰 코드로 그린 시안이 이미 들어가 있습니다
> (`scripts/make-icon-art.swift`). 사람 디자이너에게 다시 맡길 때에는 이 문서를 그대로
> 넘기면 되고, 그때 시안은 참고 자료로만 쓰면 됩니다.

## 1. 요청 내용

Moja의 앱 번들 아이콘을 만들어 주십시오. **1024 × 1024 PNG 한 장**을 납품하시면 됩니다.
나머지 크기는 개발자가 스크립트로 뽑아냅니다.

이 작업을 시작하기 전에는 `App/Resources/Assets.xcassets/AppIcon.appiconset/`에 이미지가 한 장도
없어서, macOS가 Finder와 시스템 설정 화면에서 기본 흰색 문서 아이콘을 대신 보여 주고 있었습니다.

메뉴바에 올라가는 아이콘은 이번 작업의 대상이 아닙니다. 그쪽은 SF Symbols 심볼을 코드에서 합성해
쓰고 있으며 그대로 유지합니다.

## 2. 앱에 대한 최소한의 설명

Moja는 맥에서 저장한 한글 파일 이름이 윈도우에서 깨져 보이는 문제를 자동으로 고쳐 주는 유틸리티
입니다. 메뉴바에 상주하면서 지정한 폴더를 조용히 감시하고, 네트워크는 전혀 쓰지 않습니다.

앱 이름인 '모자'는 머리에 쓰는 모자를 뜻하고, 메뉴바 아이콘도 챙이 넓은 모자입니다.

## 3. 가장 중요한 제약

이 앱은 Dock 아이콘을 띄우지 않습니다. 그래서 사용자가 아이콘을 마주치는 자리는 대부분 작습니다.

| 노출 지점 | 표시 크기 |
| --- | --- |
| 시스템 설정의 로그인 항목, 폴더 접근 권한 목록 | 16~32pt |
| Spotlight 검색 결과 | 32pt |
| 설치할 때 뜨는 Gatekeeper 경고창 | 64pt |
| Finder 응용 프로그램 폴더 | 32~128pt |

> **16pt에서 모자로 알아볼 수 있는 것이, 512pt에서 정교하게 보이는 것보다 우선합니다.**
> 세부 묘사를 넣을지 망설여지면 언제나 빼는 쪽을 선택해 주십시오.

## 4. 무엇을 그릴 것인가

**챙이 넓은 모자 하나**만 그립니다.

- 정면에서 바라보되 시선이 아주 조금 위에 있는 각도로, 챙의 타원과 크라운이 겹쳐 보이게 합니다.
- 챙은 좌우로 넓게 펼치고 크라운은 낮게 눌러서, 전체 비율이 가로로 안정되게 만듭니다.
- 챙이 넓으면 아래가 무거워 보이므로, 시각적 무게 중심을 캔버스 정중앙보다 3~4% 위에 둡니다.
- 모자 밴드는 넣어도 좋지만, 16pt에서 사라지더라도 형태가 성립해야 합니다. 시안을 만들면서
  확인한 바로는, 밴드가 두꺼우면 32pt 이하에서 모자가 흰 막대 두 개로 쪼개져 보입니다.
  크라운과 챙이 만나는 자리에 얇게 넣는 정도가 적당합니다.

한글 자모나 파일 아이콘, 화살표처럼 기능을 설명하는 요소는 넣지 않습니다. 3장에서 적은 크기
제약 때문에 전부 뭉개집니다. 앱이 무슨 일을 하는지는 온보딩 화면과 README가 설명합니다.

## 5. 스타일과 색

macOS에 기본으로 설치되는 앱 가운데 '홈', '단축어', '팟캐스트'처럼 **단색 그라디언트 배경 위에
흰색 사물 하나를 올린 구성**을 기준으로 삼습니다.

| 역할 | 값 |
| --- | --- |
| 배경 그라디언트 위 | `#5B6FE0` |
| 배경 그라디언트 아래 | `#2E3A8C` |
| 모자 | `#F7F4EC` (단색으로 채우고 그라디언트를 넣지 않습니다) |
| 모자 밴드 (선택) | `#2E3A8C` (배경 색을 그대로 재사용해 색 가짓수를 늘리지 않습니다) |

배경 그라디언트는 위가 밝고 아래가 어두워지는 세로 방향으로 넣습니다. 광원이 위에 있다고
가정하고, 그림자와 밝기 변화가 그 전제와 어긋나지 않게 합니다.

색상 값은 위의 세 개로 제한합니다. 다른 색 계열을 시도해 보고 싶다면 시안을 먼저 보여 주십시오.

## 6. 규격

| 항목 | 값 |
| --- | --- |
| 캔버스 | 1024 × 1024 px |
| 앱 도형 | 824 × 824 둥근 사각형, 캔버스 정중앙 (상하좌우 여백 각 100 px) |
| 모서리 반경 | **연속 곡률**. 흔히 인용되는 값은 185.4 px입니다 |
| 모자의 가로 폭 | 620 ~ 680 px |
| 파일 형식 | PNG, sRGB, 알파 채널 유지, 인터레이스 없음 |

모서리는 반드시 연속 곡률이어야 합니다. Figma와 Sketch의 일반 둥근 모서리 기능은 곡률 계산이
달라서 시스템 앱 옆에 놓으면 미묘하게 어긋나 보입니다. 직접 그리지 말고 Apple Design Resources의
macOS 앱 아이콘 템플릿에 들어 있는 도형을 그대로 가져다 쓰십시오.

캔버스 대비 도형 크기 80.47%(1024에 대한 824)는 macOS 메모 앱 아이콘의 알파 채널을 실측해서
확인한 값입니다. 모서리 반경은 같은 실측값에 `CALayer`의 연속 곡률을 맞춰 본 결과 180 부근에서
오차가 가장 작았고(RMS 2.5px), 널리 인용되는 185.4는 3.9px였습니다. 두 값의 차이는 128pt로
줄이면 0.5px 미만이라 실제로는 구분되지 않습니다.

둥근 사각형 바깥의 100 px 여백은 그림자가 놓일 자리입니다. 그림자도 템플릿에 포함된 것을
사용하고 직접 만들지 마십시오.

## 7. 금지 사항

- 아이콘 안에 글자를 넣지 않습니다. '모자'와 'Moja' 모두 해당합니다.
- 외곽선을 넣지 않습니다.
- 사진이나 질감 이미지를 사용하지 않습니다.
- 이모지나 SF Symbols 심볼을 그대로 확대해서 쓰지 않습니다. 심볼은 작은 크기에서 선으로 읽히도록
  설계되어 있어서, 크게 키우면 선이 빈약해 보입니다.
- 감시 중이나 오류 같은 앱의 상태를 앱 아이콘으로 구분하지 않습니다. 상태 표시는 메뉴바 아이콘이
  담당합니다.

## 8. 검수 항목

- [ ] 1024 이미지를 16px로 줄였을 때 모자로 알아볼 수 있습니다.
- [ ] 라이트 모드와 다크 모드 Finder 배경 양쪽에서 형태가 살아 있습니다.
- [ ] 흑백으로 변환해도 배경과 모자가 명도만으로 구분됩니다.
- [ ] 모서리 곡률이 시스템 앱 아이콘 옆에 놓았을 때 어긋나지 않습니다.

완성한 뒤에는 응용 프로그램 폴더에서 아이콘 크기를 가장 작게 놓고, 시스템 앱들 사이에서 Moja를
바로 찾을 수 있는지 확인해 보십시오. 눈에 들어오지 않는다면 대비가 부족하거나 형태가 복잡한
것입니다.

## 9. 함께 주시면 좋은 것 (선택)

벡터 소스 파일(SVG 또는 Figma 링크)을 함께 주시면 나중에 색이나 비율을 고칠 때 다시 그리지 않아도
됩니다. macOS의 계층형 아이콘 형식으로 넘어갈 때에도 이 파일이 있으면 작업이 훨씬 가볍습니다.
필수는 아닙니다.

## 10. 납품 이후 개발자가 할 일

1. 받은 PNG를 `scripts/make-appicon.sh`에 넘겨서 10개 크기와 `Contents.json`을 생성합니다.
   인자 없이 실행하면 `scripts/make-icon-art.swift`가 그린 시안을 씁니다.
2. `xcodegen generate` 후 `./scripts/build.sh`로 빌드하고, Finder에서 적용 여부를 확인합니다.
3. README의 설치 안내 첫 번째 스크린샷을 다시 촬영합니다. 지금 이미지에는 기본 문서 아이콘이
   찍혀 있습니다.

작은 크기를 손으로 다듬는 작업은 하지 않습니다. Apple 기본 앱은 16과 32를 따로 그리지만, 축소본이
읽히지 않을 만큼 문제가 되는 경우에만 추가로 요청하겠습니다.

계층형 `.icon` 형식(Icon Composer) 도입은 별도로 결정합니다. 이 앱은 macOS 13까지 지원하므로,
그 형식이 예전 버전용 이미지를 제대로 만들어 주는지 먼저 확인해야 합니다.
