# 위키 로그

## [2026-09-06] migrate | 한국어 정본에 영어 번역본을 짝지음

- 한국어가 정본이다. 사람이 쓰고 고치고 검토하는 쪽이 `<이름>.md`다
- 영어 번역본 `<이름>.en.md`를 세 편 새로 만들었다. 클로드가 읽고 그래프가 색인하는 쪽이다
- 정본 세 편의 본문은 손대지 않았다. 유일한 예외는 `requirements`의 번호 없는 제목 하나로,
  짝을 번호로 맞추기 위해 `### 7.1`을 주었다
- 도구: `kb.swift`가 파일의 역할(정본·번역본·장치)을 경로로 가른다. 정본을 고치면 버전을
  올리고 번역 지시서를 남기며, 번역본을 고치면 그래프와 영향 분석이 돈다
- 검색: 한국어 질문이 정본 본문에 걸리고 열어서 읽을 곳은 번역본의 절로 돌려준다
- 상호 참조: 영어에서는 `§12.4a` 표기를 쓴다. 한국어의 `장`·`절`·`참조` 표기는 그대로 산다
- `references` 엣지가 19개에서 16개로 줄었다. 회귀가 아니라 `FR-3의`·`T1의`처럼 심볼 뒤의
  조사가 절 번호로 잡히던 오탐 7건이 사라지고 진짜 참조 4건이 생긴 결과다
- `index.md`와 `log.md`는 한국어 단일본으로 남는다. `README.md`도 이 체계 바깥이다

## [2026-09-05] migrate | 프로젝트 문서를 kb/wiki로 옮김

- 이관: v1 요구사항 (`REQUIREMENTS.md` → `spec/requirements.md`)
- 이관: 수용 기준 결과 (`docs/` → `spec/`)
- 이관: `rename(2)` 저장 정규화 실측 (`docs/` → `research/`)
- 유지: `README.md`, `LICENSE`, `docs/images/`. 제품 배포물이라 저장소 루트에 남는다
- 갱신: README 링크 5곳, 문서 사이 상호 참조 3곳, Swift 주석의 문서 경로 10곳
- `kb/raw/`는 비어서 시작한다. 볼륨 실측 출력과 외부 참고 자료를 받을 자리다
