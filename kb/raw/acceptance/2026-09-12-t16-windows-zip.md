# T16: 파인더 기본 압축(zip)으로 보낸 파일을 Windows에서 열기

**Source:** 사용자 직접 확인 (대화 보고)
**Collected:** 2026-09-12
**Published:** N/A (직접 확인)
**Receiving side:** Windows (버전 미기록)

T16을 확인한 결과, macOS 기본 압축 기능으로 압축해서 Moja로 변환된 파일을 전달했을 때
Windows에서 압축을 풀어도 글자가 깨지지 않는 것을 확인함.

단, Windows의 기본 압축 앱이 동작하지 않아, 반디집으로 압축을 풀어 확인한 결과임.
기본 압축 앱은 압축 풀기 자체가 실패했으므로, 파일 이름이 어떻게 보이는지는 확인하지
못했다.

확인 횟수는 1회. Windows 버전과 반디집 버전은 기록하지 않았다.
